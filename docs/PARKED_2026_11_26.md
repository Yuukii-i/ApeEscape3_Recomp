# Parked 2026-11-26: distribution model, languages, open tests

## Distribution (discussed, NOT yet approved by the user)
- Proposed: Longshot-style. Player downloads a launcher with a free compiler bundled, picks their own disc
  image, the game is translated and built on their PC, then they just press Play. Nothing game-derived shipped.
- Rejected as risky: shipping a prebuilt exe (it contains code translated from the game).
- Build time estimate: build/.ninja_log sums to ~4.25 compiler job-hours (game code 3.92), i.e. about 30 min at
  8 jobs on the Ryzen 7 7435HS. Estimate only, no timed clean build.
- Open work: (1) a clean build from the disc must reproduce today's game: recomp_source carries script patches
  and hand edits, and tools/fix_hidden_entries.py needs logs/hidden_addrs.txt (gitignored, built from PCSX2 RAM);
  (2) move from MSVC to a bundleable compiler (untried); (3) review hand-written translations of game functions
  (e.g. decomp/ee_gfx_decomp.cpp) before claiming "no game code"; (4) move the required PS2X_ switches into
  runtime defaults so the launcher does not track game changes; (5) GPL obligations.
- Existing: tools/launcher (C++, SDL3 + Dear ImGui, docs/LAUNCHER_PLAN.md) only starts an already-built game.
- First step when resumed: test that a clean build from the disc reproduces the working game.
- Legal: not verified by a lawyer. A takedown of an OoT remake port that built locally was reported
  (finalboss.io, unverified).

## Languages (idea, not investigated)
- We use the US disc (SCUS_975.01, English only). The EU disc shows a language select before the first movie.
- Not doing: bundling EU text/audio in our releases (that is redistributing game data).
- Possible: player also supplies their own EU disc and the builder imports the languages; or original
  community translations; or a separate EU recompile (all address-keyed fixes would need porting).
- Unknown: EU file layout, text/voice formats, fonts, whether the US executable can select a language.
