## Root cause of rope + ears (do not re-derive)
Real functions called through vtables sat inside another generated function's address range with no `case` in its `switch (ctx->pc)` entry switch, so the call ran the CONTAINING function from its top and returned garbage (e.g. 0x60c4a0 inside sub_0060C3E4 returned 0, PCSX2 returns 1 -> character state machine reset -> fell). Fix = `python tools/fix_hidden_entries.py --addrs logs/hidden_addrs.txt` (1249 addrs, 296 recomp_source files patched, idempotent). The address list comes from PCSX2 save-state RAM words + lui/addiu constants that point into the middle of generated functions (candidate builder was a scratchpad script; logic: aligned word in code range, inside a function but not its start/case, preceded by jr+delay slot or `addiu sp,-N`). recomp_source is gitignored/generated: if it is ever regenerated, re-run the tool with a RAM-derived list. Backup of all recomp_source cpp: session scratchpad `recomp_bak2` (may be cleared).
