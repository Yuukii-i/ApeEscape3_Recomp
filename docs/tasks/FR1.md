# Task FR1: single-function replay harness (PS2X_FNREPLAY): run ONE recompiled guest function on a PCSX2 RAM image + registers and dump the result
Budget: "[call N/12]", stop at 12. Edit ONLY .cpp files: PS2Recomp/ps2xRuntime/src/lib/ps2_runtime.cpp (and src/main.cpp only if unavoidable). NO header edits (a header edit = multi-hour rebuild). DO NOT BUILD/RUN/COMMIT. Mark `// PROBE-FR1`.
Why: rope/cloth physics diverges in our recompiled code vs the real game. PCSX2 ground truth for one call of fn 0x340744 is captured: spec = logs/fr/fr1_spec.txt, RAM before = logs/fr/fr1_before.bin (32 MiB EE RAM), RAM after (PCSX2) = logs/fr/fr1_after.bin. We run the same function in ours on the same inputs and diff.
Design (cpp only):
1. Inside the existing member function PS2Runtime::run() (ps2_runtime.cpp; it has access to private members, so no header change), at the very START (before the normal boot/entry starts), but ON THE SAME THREAD/SETUP the game thread uses (MXCSR round-toward-zero C316 setting, FTZ/DAZ etc.: replicate exactly what the game thread does before it runs guest code; find it, e.g. grep PS2X_EE_RTZ): `if (const char* spec = std::getenv("PS2X_FNREPLAY")) { ps2xFnReplay(...); return/exit(0); }` where ps2xFnReplay is a free function defined above run() taking (uint8_t* rdram, R5900Context* ctx, PS2Runtime* rt, const char* specPath). Pass whatever run() already has for rdram/ctx/runtime.
2. Spec file = text lines (see logs/fr/fr1_spec.txt): `ram <path>` (32 MiB raw, memcpy into rdram[0..32MiB)), `pc <hex>`, `ra <hex>`, `out_ram <path>`, `out_regs <path>`, `gpr <i> w3 w2 w1 w0` (4 hex words, most significant first -> 128-bit GPR i), `hi`/`lo` (same 4 words, set the 128-bit HI/LO as the context stores them: lo/hi + lo1/hi1), `fcr31 <hex>`, `fpr <i> <hex32>`, `vf <i> w3 w2 w1 w0` (VU0 vf regs), `acc w3 w2 w1 w0`.
3. Execute: zero-init ctx first; apply the spec; set ctx->pc=pc; r31 (gpr 31) must equal `ra` from the spec (already in the gpr lines); fn = rt->lookupFunction(pc); call fn(rdram, ctx, rt) once (synchronously on this thread; the recompiled function returns to us when it executes its final jr ra). If lookupFunction returns null print an error and exit(2).
4. After the call: write the full 32 MiB rdram to out_ram, and write out_regs: for each GPR `gpr i w3 w2 w1 w0` (same format), plus `pc`, `fpr` as hex bits, `vf`, `acc`, and the line `done pc=0x%08x`.
5. Log with ps2xSafeLog `[fnreplay] ...` for each step (loaded ram, called fn, wrote outputs).
6. Do not start threads, audio, GS/renderer for this mode if that is easy to skip; if the runtime initialises them before run() it is fine as long as the replay runs and the process exits afterwards with exit(0) (use std::quick_exit/ExitProcess if clean shutdown hangs).
Acceptance: compiles (cpp only). Reply <=6 lines: where hooked, which thread/MXCSR setup replicated, how output written.
