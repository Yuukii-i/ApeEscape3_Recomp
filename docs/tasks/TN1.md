# Task TN1: print the CLUT used by 4-bit textures of the briefing tunnel (probe only; extends PS2X_RD_TEXSAVE)
Budget: "[call N/12]", stop at 12. Edit ONLY .cpp files under PS2Recomp/ps2xRuntime/src/lib/render/ (rd_texture.cpp) and gs/ if the CLUT state lives there (gs_cpu_backend.cpp, gs_frontend.cpp, ps2_vk_gs_backend.cpp). No headers. DO NOT BUILD/RUN/COMMIT. Mark `// PROBE-TN1`. Static env read once.
Evidence: PCSX2 draws the tunnel glow (blend ALPHA 0x48 additive, ~326 draws) with tbp 0x32a0 and 0x3340 (256x256). Its register sequence: TEX0 = 0x80066406213132a0 (tbp 0x32a0, tbw 4, PSM 0x13 8-bit, TW=TH=8, TCC=1, TFX=0, CBP=0x3320, CPSM=0 (CT32), CSM=0, CSA=0, CLD=4 = load CLUT if CBP != last CBP0) followed by TEX2 = 0x1400000 (PSM=0x14 4-bit, CBP=0, CPSM=0, CSM=0, CSA=0, CLD=0 = no load). So the draw samples PSMT4 data from memory that was written as PSMT8, using the 256-entry CT32 palette loaded from CBP 0x3320 by the TEX0 write (first 16 entries, CSA=0). PCSX2 shows a cyan glow; ours (logs/texdump tbp32a0_256x256_psm14*.bmp, tbp3340_256x256_psm14*.bmp) decodes these textures completely black (0 non-black pixels) while the 8-bit view of the same memory decodes fine.
Do (when PS2X_RD_TEXSAVE matches the TBP and the PSM is 4-bit, or always for 4-bit textures when PS2X_RD_CLUTLOG=1, rate 1/s per TBP):
1. Print `[clutlog] tbp=0x%04x psm=0x%02x cbp=0x%04x cpsm=0x%x csm=%d csa=%d cld=%d | activeClutSrc=<where the 512/256-entry palette array came from: GS-CPU m_clut / vk backend / rd_texture cache> | e0..e15 = 16 RGBA hex values (the first 16 entries actually used for this decode, after CSA offset)` and also the 16 entries at csa*16 of a 256-entry palette if different.
2. Print the CLUT load history for the last 8 loads: `[clutload] seq cld cbp cpsm csm csa psm entryCount firstEntryWritten firstEntryColor` (from LoadClut / LoadClutUnlocked and wherever the Vulkan backend or direct renderer loads palettes), including loads skipped because of CLD rules (print `skipped(cld=4,cbp same)` etc.) and loads skipped because `effectiveCbp == 0`.
3. Say in the reply (2-3 lines) whether the 4-bit decode of a texture whose TEX2 sets PSM 0x14 with CBP=0/CLD=0 uses the palette that the previous TEX0 (PSM 0x13, CLD=4, CBP=0x3320) loaded, or a fresh/empty one, and where `ps2xRdActiveClut()` is refreshed.
