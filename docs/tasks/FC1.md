# Task FC1: host conformance test of our EE FPU semantics vs PCSX2 ground truth
Budget: "[call N/12]", stop at 12. Create ONLY tools/fpucheck.cpp and tools/fpucheck.bat (new files). DO NOT edit runtime/recompiler sources. DO NOT RUN/COMMIT; you may NOT build either (Claude builds). Mark nothing else.
Ground truth (from real PCSX2 running guest code): logs/fr/fpu_inputs.bin = 64 pairs of uint32 float bit patterns (a,b little-endian, 8 bytes per pair); logs/fr/fpu_pcsx2_out.bin = 64 records of 12 uint32 results each (48 bytes per pair), in this op order for each pair (a=$f1, b=$f2, result $f3 raw 32-bit):
 0 add.s a+b | 1 sub.s a-b | 2 mul.s a*b | 3 div.s a/b | 4 sqrt.s of b (sqrt.s f3,f2) | 5 rsqrt.s a/sqrt(b) (rsqrt.s f3,f1,f2) | 6 adda.s(a,b) then madd.s f3,f1,f2 => ACC + a*b where ACC=a+b | 7 adda.s(a,b) then msub.s f3,f1,f2 => ACC - a*b | 8 cvt.w.s f3,f1 (raw int bits of result) | 9 cvt.s.w f3,f1 (f1's raw bits taken as int32) | 10 max.s a,b | 11 min.s a,b.
Task: write a standalone host program tools/fpucheck.cpp that computes the SAME 12 results using OUR code paths and compares bit-exactly with the PCSX2 file, printing per op: `op <name>: mismatches <n>/64` and the first 6 mismatching cases `a=0x%08x b=0x%08x pcsx2=0x%08x ours=0x%08x`.
How to get "our" semantics: read what the recompiler EMITS for these instructions (PS2Recomp/ps2xRecomp/src/lib/fpu_translator.cpp: COP1 S ops: ADD_S, SUB_S, MUL_S, DIV_S, SQRT_S (note: uses FT), RSQRT_S, MADD_S/MSUB_S/ADDA_S (ACC handling via ctx->f_acc and FPU_SET_ACC), CVT_W_S, CVT_S_W, MAX_S, MIN_S) and include PS2Recomp/ps2xRuntime/include/ps2_runtime_macros.h (FPU_ADD_S, FPU_MUL_S, FPU_DIV_S, FPU_SQRT_S, FPU_RSQRT_S, ps2_fadd/ps2_fmul/ps2_fdiv/ps2_fsqrt/ps2_frsqrt, FPU_MAX_S...) and call exactly those macros in the same way the emitted code does, so the test exercises the real code. The header includes ps2_runtime.h: provide minimal stubs for any undefined externs (e.g. `void ps2xFpuProbe(void*,int){}`, `bool ps2xFpuProbeEnabled(){return false;}`, g_ps2wwBase/g_ps2wwLen/ps2xGuestWriteHit etc.) in the test file. If the header cannot be included standalone, COPY the needed inline helper functions (ps2_fall_normal, ps2_fadd/ps2_fmul/ps2_fdiv/ps2_fsqrt/ps2_frsqrt and their *_slow versions, ps2_to_double, ps2_from_double, constants) verbatim into the test with a comment naming the source lines.
