# Task RW1: generic EE-RAM range printer (probe only, env PS2X_RAMWATCH="0xADDR:LEN,0xADDR:LEN,...")
Budget: "[call N/12]", stop at 12. Edit ONLY PS2Recomp/ps2xRuntime/src/lib/ps2_runtime.cpp (or the .cpp that owns the 1 s scheduler/vblank tick and the guest RAM pointer; EeScheduler.cpp VBlankStart handler is fine). No headers. DO NOT BUILD/RUN/COMMIT. Mark `// PROBE-RW1`. Static parse once; unset = one bool test per vblank.
Why: compare guest memory of our port against PCSX2 at the same game moment without touching the emulator. Example use: level-select preview: PCSX2 (state slot 7) has GIF strip packets at EE 0x00a35f50 (+0x80 each, 16 of them, TRXREG qword `10 00 00 00 00 01 00 00 52 00 00 00 00 00 00 00`) and decoded RGBA source pixels at 0x01c47480 (and 0x01c50000).
Do (only when PS2X_RAMWATCH is set): once per second (guest vblank multiples of 60 or host 1 s) print for each range `[ramwatch] t=%llums addr=0x%08x len=%u nonzero=%u sum=0x%08x first32=%02x %02x ...` (first 32 bytes hex; for len>32 also min/max byte). Ranges are physical EE RAM offsets (mask 0x1FFFFFFF); clamp to 32 MB; max 8 ranges, len up to 1 MB. Additionally support `PS2X_RAMWATCH_SCAN=<hex bytes with ?? wildcards>` that, once per 2 s, scans EE RAM 0x100000..0x2000000 for the pattern and prints up to 8 hit addresses `[ramscan] hits=%u first=0x...,0x...` (use a fast memchr-first-byte loop; cap the scan to 4 ms).
No behaviour change.
Accept: compiles; reply <=3 lines with file/line ranges.
