PCSX2 facts (slot 3 ear scene, EE frame loop fn entry 0x51E204): per frame it calls sceGsSyncPath(0,0)=0x404230 (0x51E288), then 0x440D48 = the game's clock read: it reads EE TIMER1 count (0x10001000, lwu) and mode (0x10001010; bit 0x800 = overflow flag, low 2 bits = clock divider select), combines with an overflow counter in RAM at 0x006A2E20 (64-bit, incremented by the timer1 overflow interrupt handler, shifted <<16), and the frame loop compares (now - [0x0072D490]) to a limit and loops through sceGsSyncV (0x404198) until enough time elapsed. Problem: in replay (g_fnReplayActive) our timer accounting is gated off, so TIMER1 never advances, the frame loop never sees elapsed time, and iteration 1 re-enters 0x404230 forever (skip hits repeat, BLOCKED).
